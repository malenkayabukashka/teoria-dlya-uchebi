## Списковое включение

синтаксическая конструкция в Python для создания нового списка на основе существующего итерируемого объекта с применением фильтрации и/или преобразования элементов.

**Почему это быстрее обычного цикла с .append()?**

Когда ты пишешь обычный цикл:
```python
result = []
for item in iterable:
    if condition:
        result.append(item)
```

На каждой итерации интерпретатор Python должен:

1. Найти метод `.append` в словаре атрибутов объекта `result` (attribute lookup).
2. Вызвать этот метод как функцию (function call overhead).
3. Динамически проверять и, при необходимости, перевыделять память для списка.

В случае со списковым включением:
```python
result = [item for item in iterable if condition]
```

Интерпретатор CPython использует оптимизированную байт-код инструкцию `LIST_APPEND`. Он заранее (насколько это возможно) оценивает размер итогового списка, избегает поиска атрибута .append на каждой итерации и выполняет всё это на уровне C-кода интерпретатора, что значительно снижает накладные расходы.

**Создание списка квадратов четных чисел.**
```python
# Менее эффективно
squares = []
for x in range(100):
    if x % 2 == 0:
        squares.append(x ** 2)

# Более эффективно и "питонично"
squares = [x ** 2 for x in range(100) if x % 2 == 0]
```

## Модуль timeit

стандартный модуль Python, предназначенный для точного измерения времени выполнения небольших фрагментов кода.

**Почему не использовать time.time() или time.perf_counter() вручную?**

Обычные таймеры подвержены влиянию фоновых процессов операционной системы, планировщика задач и сборки мусора (Garbage Collector, GC). Модуль timeit решает эти проблемы:

1. Он временно отключает сборщик мусора на время замера, чтобы внезапная очистка памяти не исказила результат.
2. Он выполняет код множество раз (по умолчанию 1 000 000), чтобы нивелировать случайные колебания и получить статистически значимое среднее или минимальное время.

**Как использовать:**

Функция `timeit.timeit(stmt, setup, number)`

* `stmt` (statement): код, который нужно измерить. Может быть строкой или вызываемым объектом (функцией).
* `setup`: код инициализации (например, импорты или создание исходных данных), который выполняется один раз перед замером. Также может быть строкой или функцией.
* `number`: количество повторений выполнения `stmt`.
```python
import timeit

def my_func():
    return [x for x in range(1000)]

# Измеряем время выполнения my_func 10 000 раз
# Мы передаем саму функцию как stmt, что удобнее и безопаснее, чем строка
execution_time = timeit.timeit(stmt=my_func, number=10000)
print(f"Время: {execution_time}")
```
Использовать `lambda-функцию`, чтобы создать "обертку" без аргументов, которая внутри себя вызовет нашу функцию с нужными данными.
```python
import timeit

# Пример (не из задания):
my_list = [1, 2, 3]

# Неправильно: timeit.timeit(sum(my_list)) 
# Правильно: передаем lambda, которая не требует аргументов при вызове из timeit
execution_time = timeit.timeit(stmt=lambda: sum(my_list), number=1000000)
```
Обрати внимание: мы передаем саму `lambda` как объект, без скобок в конце! А параметр `number` говорит `timeit`, сколько раз повторить этот вызов.

💡 Лайфхак Python: Для удобства чтения больших чисел можно использовать подчеркивания: 90_000_000. Python игнорирует их, но тебе будет гораздо легче не ошибиться в нулях.

## map()

встроенная функция, которая применяет заданную функцию к каждому элементу итерируемого объекта и возвращает итератор (в Python 3).

Ключевая особенность map() в Python 3 — ленивые вычисления. Функция не создаёт весь новый список сразу, а возвращает итератор, который вычисляет значения только в тот момент, когда вы их запрашиваете (например, при переборе в цикле for или преобразовании в list()). Это экономит память при работе с большими объёмами данных. 


В Python 3 функция map() ленивая (lazy evaluation). Она не вычисляет результаты сразу, а просто создает объект-итератор.

Если ты замеришь время просто map(...), timeit покажет тебе время создания этого итератора, которое будет искусственно близко к 0. Это будет нечестное сравнение с циклом и списковым включением, которые сразу создают и заполняют список в памяти.

Правило: Чтобы сравнение было честным, мы должны материализовать результат, обернув его в `list()`: list(map(...)).

Функция `map` создана для преобразования (1 к 1), а не для фильтрации. Она обязана вернуть ровно столько же элементов, сколько получила (в нашем случае 25).
Чтобы сымитировать фильтрацию, мы можем использовать тернарный оператор, который вы знакомы: возвращать сам адрес, если в нем есть `'gmail'`, и `None` (или пустую строку `''`) в противном случае.

Пример: сложение соответствующих элементов двух списков.
```python
numbers1 = [1, 2, 3]
numbers2 = [10, 20, 30]
result = list(map(lambda x, y: x + y, numbers1, numbers2))
print(result)  # [11, 22, 33]
```
Важный момент: если длины коллекций не совпадают, `map()` остановится, как только закончится самая короткая из них (поведение аналогично функции `zip()`). В Python 3.14+ можно использовать параметр `strict=True`, чтобы при несовпадении длин генерировалось исключение `ValueError`.

Преобразование строк в верхний регистр:
```python
words = ["hello", "world", "python"]
uppercase_words = map(str.upper, words)
print(list(uppercase_words))  # ['HELLO', 'WORLD', 'PYTHON']
```
Возведение чисел в квадрат:
```python
numbers = [1, 2, 3, 4, 5]
squares = map(lambda x: x ** 2, numbers)
print(list(squares))  # [1, 4, 9, 16, 25]
```
**Когда стоит использовать map()**
* Когда нужно применить одну и ту же операцию к каждому элементу коллекции.
* При работе с большими данными благодаря ленивой обработке.
* Когда уже есть готовая функция для преобразования, и не нужна сложная логика в виде лямбды.
```python
# Пример логики (не полное решение):
lambda x: x if 'gmail' in x else None
```
Вместо громоздких `if/elif/else`, мы можем сделать это в две строки:
```python
# Пример (не из задания):
times = {
    "loop": time_loop,
    "list comprehension": time_comp,
    "map": time_map
}

# min с key=times.get найдет ключ, у которого значение (время) минимально
best_method = min(times, key=times.get) 
print(f"it is better to use a {best_method}")

# А для вывода чисел по возрастанию используем sorted() и генератор с .join()
print(" vs ".join(str(t) for t in sorted(times.values())))
```
`map(функция, итерируемый_объект, [итерируемый_объект2, ...])`
* **функция**— операция, которая применяется к каждому элементу (может быть пользовательской, встроенной или лямбда-функцией).
* **итерируемый_объект** — объект, по элементам которого выполняется итерация (список, кортеж, строка и т. д.).
Дополнительные итерируемые объекты — необязательные. Если передать несколько коллекций, map() будет брать элементы из каждой параллельно. Итерация остановится, как только закончится самая короткая коллекция.

## Filter и динамический вызов функций

Определение: `filter(function, iterable)` создает итератор из тех элементов итерируемого объекта, для которых функция возвращает истинное значение (`True` или `truthy value`).

Её задача: отобрать из итерируемого объекта (списка, кортежа, генератора и т.п.) только те элементы, которые удовлетворяют заданному условию. 

Как это работает: вы передаёте filter() два аргумента. Первый — функция-критерий (она должна принимать один аргумент и возвращать True или False), второй — итерируемый объект. Для каждого элемента filter() вызывает вашу функцию с этим элементом в качестве аргумента. Если функция вернула True, элемент попадает в результат, если False — пропускается. В итоге вы получаете итератор (в Python 3) — его часто нужно преобразовать в список, кортеж и т.п..

Отбираем только чётные числа: `filter(lambda x: x % 2 == 0, numbers)`

Оставляем в списке только строки длиннее 5 букв: `filter(lambda w: len(w) > 5, words)`

Можно использовать и встроенные методы — если они подходят под условие (например, `str.isalpha()` отбирает только буквы из строки). 

Часто в паре с `filter()` используют лямбда-выражения — для простых, одноразовых условий не нужно писать отдельную именованную функцию.

**Ловушка ленивости (аналогично map):**

В Python 3 `filter` возвращает не список, а объект-итератор. Он не выполняет работу сразу. Если мы замерим время просто `filter(...)`, мы измерим лишь время создания итератора (около 0.00001 сек), что будет нечестным сравнением с циклом, который сразу строит список в памяти.

Для честного бенчмаркинга мы обязаны материализовать результат: `list(filter(...))`.

Ты уже знаешь, что в Python функции являются объектами первого класса (first-class citizens). Это значит, что их можно хранить в переменных, передавать как аргументы и хранить в словарях!

Вместо громоздкой конструкции:
```python
if func_name == "loop":
    time = timeit.timeit(stmt=lambda: get_gmail_loop(data), number=runs)
elif func_name == "list_comprehension":
    # ... и так далее
```

Мы можем использовать словарь для маппинга (сопоставления) строки из `sys.argv` на реальную функцию:
```python
# Пример (не из задания):
actions = {
    "run": my_run_function,
    "stop": my_stop_function
}
# Вызов: actions["run"]()
```
Этот паттерн (Dictionary Dispatch) делает код чистым, масштабируемым и профессиональным.

## sys.argv и Guard Clause (напоминание)

Ты знаешь, что sys.argv — это список строк.
* `sys.argv[0]` — имя скрипта.
* `sys.argv[1]` — имя функции (например, "`filter`").
* `sys.argv[2]` — число вызовов (строка, которую нужно преобразовать через `int()`).
* `Guard Clause`: Если len(sys.argv) != 3, скрипт должен просто молча завершить работу (ничего не выводить), как показано в последнем примере задания: `$ ./benchmark.py`.

## Reduce

`reduce(function, iterable[, initializer])` — это функция из модуля `functools`, которая последовательно применяет функцию двух аргументов к элементам итерируемого объекта, сворачивая (reducing) всю последовательность до одного единственного значения

Если у нас есть список [1, 2, 3, 4] и функция сложения, `reduce` сделает следующее:

* Берет первые два элемента: `1` и `2`, применяет функцию: `1 + 2 = 3`.
* Берет результат (`3`) и следующий элемент (`3`): `3 + 3 = 6`.
* Берет результат (`6`) и следующий элемент (`4`): `6 + 4 = 10`.
* Возвращает `10`.

## Counter

специализированный словарь из модуля `collections`, предназначенный для подсчёта частоты элементов в итерируемом объекте. Он наследуется от `dict`, поэтому поддерживает все методы словаря, но добавляет собственные оптимизированные методы для работы с частотами.

`Counter` реализован на C внутри интерпретатора CPython. Когда ты вызываешь `Counter(iterable)`, подсчёт происходит на уровне C-кода, минуя накладные расходы Python-циклов. Это в разы быстрее, чем ручной перебор элементов в Python-коде.

**Создание Counter:**
```python
from collections import Counter

data = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]
counter = Counter(data)
# Результат: Counter({4: 4, 3: 3, 2: 2, 1: 1})
```

**Метод most_common(n):**

Возвращает список из `n` самых частых элементов в виде кортежей (элемент, частота), отсортированных по убыванию частоты.
```python
counter.most_common(3)
# Результат: [(4, 4), (3, 3), (2, 2)]
```
Если n не указан, возвращает все элементы, отсортированные по частоте.

**Доступ к частоте:**
```python
counter[4]  # Вернёт 4
counter[99] # Вернёт 0 (не KeyError, как у обычного dict!)
```

**Как использовать Counter для подсчёта частот**

`Counter` — это специализированный словарь, оптимизированный для подсчёта частот. Он реализован на C, поэтому работает в разы быстрее самописного цикла.
```python
from collections import Counter

data = [1, 2, 2, 3, 3, 3]
counter = Counter(data)
# Результат: Counter({3: 3, 2: 2, 1: 1})
```
`Counter(data)` принимает любой итерируемый объект и возвращает объект, который ведёт себя как словарь, но с оптимизированными методами.
