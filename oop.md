# Введение в Python: ООП

### ООП (Объектно-Ориентированное Программирование) 
— это парадигма, в которой программа строится не как набор разрозненных функций, а как набор объектов, которые взаимодействуют друг с другом.

| Концепция | Аналогия |
|--|--|
| Класс | Чертёж дома (описание: сколько комнат, где двери, какого цвета стены) |
| Объект (экземпляр класса) | Конкретный дом, построенный по этому чертежу |
| Атрибуты | Характеристики дома: адрес, цвет, количество этажей |
| Методы | Действия, которые дом может "делать": открыть дверь, включить свет | 

**Класс** — это шаблон или «чертёж» для создания объектов. Он определяет структуру данных (атрибуты) и поведение (методы), которые будут общими для всех объектов данного типа. 

**Объект (экземпляр класса)** — это конкретная реализация этого шаблона с определёнными значениями атрибутов. 

**Атрибуты** — это переменные, связанные с классом или объектом, которые хранят данные. В Python есть два основных типа:

* Атрибуты класса — общие для всех экземпляров класса.
* Атрибуты экземпляра — уникальные для каждого объекта.
 
**Методы** — это функции, определённые внутри класса, которые описывают поведение объектов. Первый параметр метода экземпляра всегда называется self — это ссылка на текущий объект, через которую метод получает доступ к его атрибутам. 

**Конструктор** — это специальный метод __init__, который автоматически вызывается при создании нового объекта. Его задача — инициализировать объект, задав начальные значения его атрибутам. 

## Четыре принципа ООП

**Инкапсуляция.** Это объединение данных и методов, которые работают с этими данными, в единую сущность (класс) и ограничение прямого доступа к внутренним данным объекта. В Python нет жёстких механизмов контроля доступа, как в некоторых других языках, но принято использовать соглашения: префикс одинарного подчёркивания _ для защищённых атрибутов и двойного подчёркивания __ для приватных. Для контролируемого доступа часто используют @property — это позволяет добавлять логику при чтении или изменении атрибутов. 

**Наследование.** Механизм, который позволяет создавать новые классы на основе существующих, заимствуя их свойства и методы. Это обеспечивает повторное использование кода, создание иерархий классов, которые моделируют взаимосвязи сущностей, и расширение функциональности без модификации базового класса. 

**Полиморфизм.** Это способность объектов разных классов реагировать по-разному на одни и те же методы. Он позволяет использовать единый интерфейс для различных базовых форм (типов данных). В Python полиморфизм часто реализуется через переопределение методов в дочерних классах. Также к нему можно отнести и перегрузку операторов. 

**Абстракция.** Это выделение значимых характеристик объекта и игнорирование незначимых деталей. В Python для реализации абстракции используются абстрактные классы и методы, которые определяются с помощью модуля abc. Абстрактный класс не может быть инстанциирован напрямую и служит для группировки родственных классов. 

## 🐍 Классы в Python: синтаксис

**Базовый скелет класса**
```python
class MyClass:
    # Тело класса: атрибуты и методы
    pass
```
* Имя класса — `CamelCase` (например, `MustRead`, `Research`, `Analytics`)
* Имя файла — `snake_case` (например, `first_class.py`, `make_report.py`)

Когда Python встречает `class`, он:

* Создаёт объект-класс (это тоже объект, но особый)
* Запоминает все методы и атрибуты внутри
* Позволяет позже создавать экземпляры этого класса

**🧩 Атрибуты класса vs Атрибуты экземпляра**

      Атрибуты класса (общие для всех экземпляров)
```python
class Counter:
    total_created = 0  # атрибут класса — общий для всех
    
    def __init__(self):
        Counter.total_created += 1
```
      Атрибуты экземпляра (уникальные для каждого объекта)
```python
class Person:
    def __init__(self, name):
        self.name = name  # атрибут экземпляра

class Person:
    def __init__(self, name, age):
        self.name = name    # ← атрибут ЭКЗЕМПЛЯРА, свой у каждого
        self.age = age

p1 = Person("Alice", 30)
p2 = Person("Bob", 25)

print(p1.name)    # ← "Alice"
print(p2.name)    # ← "Bob"
```
| Характеристика | Атрибут класса | Атрибут экземпляра | 
|--|--|--|
| Где объявляется| В теле класса, вне методов | Внутри __init__ (или других методов) 
| Cинтаксис | attr = value | self.attr = value
| Кому принадлежит | Классу (один на всех) | Конкретному объекту |
| Доступ | ClassName.attr или obj.attr | Только obj.attr
| Изменение | Меняется у всех объектов сразу| Меняется только у одного объекта |

**🔗 Как методы используют атрибуты экземпляра**

После того как мы сохранили данные в self.attr, любой метод класса может их использовать:
```python
class FileProcessor:
    def __init__(self, filename):
        self.filename = filename      # ← сохраняем имя файла
    
    def read(self):
        with open(self.filename, 'r') as f:    # ← используем атрибут
            return f.read()
    
    def get_name(self):
        return self.filename          # ← используем атрибут

obj = FileProcessor("data.csv")
print(obj.read())         # ← прочитает data.csv
print(obj.get_name())     # ← выведет "data.csv"
```
`self` — это "мост" между методами одного объекта. Благодаря `self` метод `read()` "знает", с каким файлом работать, хотя этот файл был указан при создании объекта.

**🛠️ Методы класса**

Метод — это функция, определённая внутри класса. Главная особенность — первый параметр всегда `self`.

`self` — это ссылка на конкретный экземпляр класса, который вызывает метод. Благодаря `self` метод "знает", с каким объектом он работает.
```python
class Greeter:
    def say_hello(self):
        print("Hello!")

g = Greeter()       # создаём экземпляр
g.say_hello()       # вызываем метод (self передаётся автоматически)
```
Когда ты пишешь `g.say_hello()`, Python на самом деле делает `Greeter.say_hello(g)`. То есть `self` — это и есть `g`.

*🪄 Магические (dunder) методы*

Методы с двойным подчёркиванием `__` имеют специальное значение:

| Метод | Когда вызывается |
|--|--|
| __init__(self) | При создании объекта (obj = MyClass()) |
| __str__(self) | При print(obj) |
| __repr__(self) | При выводе объекта в REPL |
| __len__(self) | При len(obj) |

*📖 Пример: простой класс с методом*
```python
class FileProcessor:
    file_name = "data.txt"  # атрибут класса
    
    def read_content(self):
        with open(self.file_name, 'r', encoding='utf-8') as f:
            content = f.read()
        print(content)

# Использование:
processor = FileProcessor()
processor.read_content()
```
1. Создали класс `FileProcessor`
2. Внутри — атрибут `file_name` и метод `read_content`
3. Создали экземпляр `processor`
4. Вызвали метод `read_content()` — он прочитал файл и вывел содержимое

**Параметры по умолчанию в методах**

Это параметр, который не обязательно передавать при вызове метода. Если не передали — используется значение по умолчанию.
```python
def greet(name, greeting="Привет"):
    print(f"{greeting}, {name}!")

greet("Алиса")              # → "Привет, Алиса!" (используется значение по умолчанию)
greet("Боб", "Здравствуй")  # → "Здравствуй, Боб!" (передали своё значение)

def method(self, param1, param2=default_value):
    # param2 можно не передавать
```
Важно: параметры со значениями по умолчанию должны идти после обязательных параметров.

## Конструктор

это специальный метод, который автоматически вызывается при создании объекта. Его задача — инициализировать состояние объекта (то есть задать его атрибуты).

**🔑 Ключевые особенности __init__()**

* Имя всегда `__init__` (два подчёркивания с каждой стороны — "dunder method")
* Первый параметр — `self` (как у любого метода)
* Вызывается автоматически при `obj = ClassName(...)`
* Ничего не возвращает (даже `return None` писать не нужно)
* Принимает любые параметры — именно через них мы настраиваем объект

**🧩 Синтаксис конструктора**
```python
class MyClass:
    def __init__(self, param1, param2):
        self.attr1 = param1      # ← сохраняем в атрибут экземпляра
        self.attr2 = param2      # ← сохраняем в атрибут экземпляра

# Создание объекта с параметрами:
obj = MyClass("value1", "value2")
```
**🎬 Что происходит при obj = MyClass("value1", "value2")?**
```python
# 1. Создаёт пустой объект
# 2. Вызывает __init__(obj, "value1", "value2")
#    - self.attr1 = "value1"
#    - self.attr2 = "value2"
# 3. Возвращает готовый объект
```
Конструктор — идеальное место для проверки входных данных. Если данные некорректны, нужно сразу выбросить исключение.
```python
def __init__(self, value):
    if value < 0:
        raise ValueError("Value must be non-negative")
    self.value = value
```
raise — это команда, которая принудительно выбрасывает исключение. Когда исключение выброшено:
* Выполнение метода немедленно прерывается
* Python ищет ближайший `try/except` выше по стеку
* Если `try/except` нет — программа падает с ошибкой

## Вложенный класс 

Когда у тебя есть класс, который логически связан с другим классом, но не должен использоваться отдельно, ты можешь вложить его внутрь. Это помогает:

* Структурировать код — связанные классы находятся вместе
* Скрыть детали реализации — вложенный класс не "загрязняет" глобальное пространство имён
* Показать иерархию — вложенный класс "принадлежит" внешнему

Представь автомобиль (внешний класс) и двигатель (вложенный класс):
* Двигатель — часть автомобиля
* Двигатель не существует отдельно от автомобиля
* Логично определить двигатель внутри автомобиля
```python
class Car:
    class Engine:
        def start(self):
            print("Двигатель запущен")
    
    def drive(self):
        engine = Car.Engine()
        engine.start()
        print("Автомобиль едет")
```
**🧩 Синтаксис вложенного класса**
```python
class OuterClass:
    # Атрибуты и методы внешнего класса
    
    class InnerClass:
        # Атрибуты и методы вложенного класса
        
        def inner_method(self):
            return "Я вложенный метод"
    
    def outer_method(self):
        inner = OuterClass.InnerClass()
        return inner.inner_method()
```
**🔑 Ключевые моменты**
1. Вложенный класс определяется внутри тела внешнего класса
2. Вложенный класс НЕ имеет автоматического доступа к `self` внешнего класса — это не Java!
3. Создать экземпляр вложенного класса можно так: `OuterClass.InnerClass()`
4. Вложенный класс — это просто способ организации кода, он не имеет особой магии

## Наследование 

это механизм, при котором один класс (дочерний, subclass) получает все свойства и методы другого класса (родительского, superclass), и может их расширять или переопределять.

**🧩 Синтаксис наследования в Python**
```python
class Parent:
    def parent_method(self):
        return "Я метод родителя"

class Child(Parent):          # ← Child наследует от Parent
    def child_method(self):
        return "Я метод ребёнка"

# Использование:
obj = Child()
obj.parent_method()    # ✅ работает — унаследован от Parent
obj.child_method()     # ✅ работает — свой метод Child
```
**🔑 Ключевые моменты**
1. Синтаксис: `class Child(Parent)`: — в скобках указывается родительский класс
2. Дочерний класс получает ВСЕ методы и атрибуты родителя
3. Дочерний класс может добавлять свои методы
4. Дочерний класс может переопределять методы родителя
5. Множественное наследование возможно: `class Child(Parent1, Parent2)`

**🔄 Переопределение методов**

Если дочерний класс определяет метод с тем же именем, что и у родителя — метод переопределяется:
```python
class Parent:
    def greet(self):
        return "Привет от родителя"

class Child(Parent):
    def greet(self):              # ← переопределение
        return "Привет от ребёнка"

obj = Child()
obj.greet()   # → "Привет от ребёнка" (вызывается метод Child)
```

**🔗 Использование методов родителя через super()**

Иногда дочерний класс хочет расширить метод родителя, а не полностью его заменить. Для этого используется super():
```python
class Parent:
    def greet(self):
        return "Привет"

class Child(Parent):
    def greet(self):
        parent_greeting = super().greet()   # ← вызываем метод родителя
        return f"{parent_greeting}, мир!"

obj = Child()
obj.greet()   # → "Привет, мир!"
```
*Когда дочерний класс хочет добавить функциональность к родительскому методу, а не заменить его полностью.*

**🏗️ Конструкторы при наследовании**

Если у родительского класса есть `__init__`, дочерний класс не наследует его автоматически. Нужно вызывать его явно через `super().__init__()`:
```python
class Parent:
    def __init__(self, name):
        self.name = name

class Child(Parent):
    def __init__(self, name, age):
        super().__init__(name)   # ← вызываем конструктор родителя
        self.age = age           # ← добавляем свой атрибут

obj = Child("Алиса", 30)
print(obj.name)   # → "Алиса" (от родителя)
print(obj.age)    # → 30 (свой)
```
## Модуль

Модуль — это просто Python-файл (`.py`), который содержит код. Любой файл с расширением `.py` — это модуль.

* Модуль = книга в библиотеке
* Класс = глава в книге
* Метод = параграф в главе
* Импорт = взять книгу с полки и пользоваться ею

**Синтаксис импорта**
```python
# Вариант 1: импортировать весь модуль
import config
config.NUM_STEPS           # ← доступ через имя модуля

# Вариант 2: импортировать конкретное имя
from config import NUM_STEPS
NUM_STEPS                  # ← доступ напрямую

# Вариант 3: импортировать несколько имён
from config import NUM_STEPS, REPORT_TEMPLATE
```
Когда ты пишешь `import config`, Python:\
1. Ищет файл `config.py` в текущей директории (и в `sys.path`)
2. Выполняет его целиком (сверху вниз)
3. Все имена, определённые в `config.py`, становятся доступны через `config.xxx`

**🧩 Блок if __name__ == '__main__': — зачем он нужен?**

Это магическая конструкция, которая позволяет отличить:
* Запуск файла как скрипта (напрямую: python3 file.py)
* Импорт файла как модуля (через import file)

Когда Python запускает файл напрямую:
```python
__name__ == '__main__'   # → True
```

Когда Python импортирует файл:
```python
__name__ == 'имя_файла'  # → False (например, 'config')
```

**💡 Практическое правило**

Весь код, который должен выполняться только при прямом запуске (тесты, запуск программы), помещай внутрь `if __name__ == '__main__'`:.

В модулях, которые предназначены для импорта (как `config.py` и `analytics.py`), этот блок не нужен.

    # Валидация заголовка
    header = lines[0]
    if not is_valid_header(header):
        raise ValueError("Invalid header")
    
    # Валидация данных
    for line in lines[1:]:
        clean_line = line.strip()
        if not is_valid_data(clean_line):
            raise ValueError("Invalid data")
    
    return lines

from random import randint

def generate_random(num_steps):
    result = []
    for _ in range(num_steps):
        coin = randint(0, 1)
        result.append([coin, 1 - coin])
    return result
