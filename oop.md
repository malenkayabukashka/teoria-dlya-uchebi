# Введение в Python: ООП

### ООП (Объектно-Ориентированное Программирование) 
— это парадигма, в которой программа строится не как набор разрозненных функций, а как набор объектов, которые взаимодействуют друг с другом.

| Концепция | Аналогия |
|--|--|
| Класс | Чертёж дома (описание: сколько комнат, где двери, какого цвета стены) |
| Объект (экземпляр класса) | Конкретный дом, построенный по этому чертежу |
| Атрибуты | Характеристики дома: адрес, цвет, количество этажей |
| Методы | Действия, которые дом может "делать": открыть дверь, включить свет | 

**Класс** — это шаблон или «чертёж» для создания объектов. Он определяет структуру данных (атрибуты) и поведение (методы), которые будут общими для всех объектов данного типа. 

**Объект (экземпляр класса)** — это конкретная реализация этого шаблона с определёнными значениями атрибутов. 

**Атрибуты** — это переменные, связанные с классом или объектом, которые хранят данные. В Python есть два основных типа:

* Атрибуты класса — общие для всех экземпляров класса.
* Атрибуты экземпляра — уникальные для каждого объекта.
 
**Методы** — это функции, определённые внутри класса, которые описывают поведение объектов. Первый параметр метода экземпляра всегда называется self — это ссылка на текущий объект, через которую метод получает доступ к его атрибутам. 

**Конструктор** — это специальный метод __init__, который автоматически вызывается при создании нового объекта. Его задача — инициализировать объект, задав начальные значения его атрибутам. 

## Четыре принципа ООП

**Инкапсуляция.** Это объединение данных и методов, которые работают с этими данными, в единую сущность (класс) и ограничение прямого доступа к внутренним данным объекта. В Python нет жёстких механизмов контроля доступа, как в некоторых других языках, но принято использовать соглашения: префикс одинарного подчёркивания _ для защищённых атрибутов и двойного подчёркивания __ для приватных. Для контролируемого доступа часто используют @property — это позволяет добавлять логику при чтении или изменении атрибутов. 

**Наследование.** Механизм, который позволяет создавать новые классы на основе существующих, заимствуя их свойства и методы. Это обеспечивает повторное использование кода, создание иерархий классов, которые моделируют взаимосвязи сущностей, и расширение функциональности без модификации базового класса. 

**Полиморфизм.** Это способность объектов разных классов реагировать по-разному на одни и те же методы. Он позволяет использовать единый интерфейс для различных базовых форм (типов данных). В Python полиморфизм часто реализуется через переопределение методов в дочерних классах. Также к нему можно отнести и перегрузку операторов. 

**Абстракция.** Это выделение значимых характеристик объекта и игнорирование незначимых деталей. В Python для реализации абстракции используются абстрактные классы и методы, которые определяются с помощью модуля abc. Абстрактный класс не может быть инстанциирован напрямую и служит для группировки родственных классов. 

## 🐍 Классы в Python: синтаксис

**Базовый скелет класса**
```python
class MyClass:
    # Тело класса: атрибуты и методы
    pass
```
* Имя класса — `CamelCase` (например, `MustRead`, `Research`, `Analytics`)
* Имя файла — `snake_case` (например, `first_class.py`, `make_report.py`)

Когда Python встречает `class`, он:

* Создаёт объект-класс (это тоже объект, но особый)
* Запоминает все методы и атрибуты внутри
* Позволяет позже создавать экземпляры этого класса

**🧩 Атрибуты класса vs Атрибуты экземпляра**

      Атрибуты класса (общие для всех экземпляров)
```python
class Counter:
    total_created = 0  # атрибут класса — общий для всех
    
    def __init__(self):
        Counter.total_created += 1
```
      Атрибуты экземпляра (уникальные для каждого объекта)
```python
class Person:
    def __init__(self, name):
        self.name = name  # атрибут экземпляра
```
**🛠️ Методы класса**

Метод — это функция, определённая внутри класса. Главная особенность — первый параметр всегда `self`.

`self` — это ссылка на конкретный экземпляр класса, который вызывает метод. Благодаря `self` метод "знает", с каким объектом он работает.
```python
class Greeter:
    def say_hello(self):
        print("Hello!")

g = Greeter()       # создаём экземпляр
g.say_hello()       # вызываем метод (self передаётся автоматически)
```
Когда ты пишешь `g.say_hello()`, Python на самом деле делает `Greeter.say_hello(g)`. То есть `self` — это и есть `g`.

*🪄 Магические (dunder) методы*

Методы с двойным подчёркиванием `__` имеют специальное значение:

| Метод | Когда вызывается |
|--|--|
| __init__(self) | При создании объекта (obj = MyClass()) |
| __str__(self) | При print(obj) |
| __repr__(self) | При выводе объекта в REPL |
| __len__(self) | При len(obj) |

*📖 Пример: простой класс с методом*
```python
class FileProcessor:
    file_name = "data.txt"  # атрибут класса
    
    def read_content(self):
        with open(self.file_name, 'r', encoding='utf-8') as f:
            content = f.read()
        print(content)

# Использование:
processor = FileProcessor()
processor.read_content()
```
1. Создали класс `FileProcessor`
2. Внутри — атрибут `file_name` и метод `read_content`
3. Создали экземпляр `processor`
4. Вызвали метод `read_content()` — он прочитал файл и вывел содержимое
