# UNIX: инструменты командной строки

Командная оболочка (shell) — это программа, которая принимает команды, введенные с клавиатуры, и передает их операционной системе для выполнения.

Практически все дистрибутивы Linux поставляются с командной оболочкой из проекта GNU, которая называется **bash**. Имя bash — это аббревиатура от *Bourne Again Shell*, отражающая тот факт, что bash является улучшенной заменой `sh` — первоначальной командной оболочки для Unix, написанной Стивом Борном (Steve Bourne).

---

## 1. Основы работы с Bash

### Переменные

* **Создать переменную:**
  ```bash
  MY_NAME="Алиса"
  ```
* **Обратиться к переменной:**
  ```bash
  echo $MY_NAME
  ```
* **Вставить переменную внутрь строки:**
  ```bash
  echo "Привет, ${MY_NAME}!"
  ```

### Подстановка команд (Command Substitution)

Позволяет выполнить команду и подставить её результат прямо в строку или переменную:

```bash
TODAY=$(date +%Y-%m-%d)
echo "Сегодня $TODAY"
# Вывод: Сегодня 2026-10-23
```

## 2. Конвейеры и перенаправление потоков

### Конвейер (Pipe) `|`

Передаёт вывод (`stdout`) одной команды как ввод (`stdin`) для следующей. Читается слева направо.

```bash
ls | grep ".json"
```
* `ls` — выводит список всех файлов.
* `|` — передаёт список дальше.
* `grep ".json"` — отфильтровывает строки, оставляя только содержащие `.json`.

```bash
echo "привет мир" | wc -w
# Выведет: 2 (посчитано количество слов)
```

### Перенаправление вывода (`>` и `<`)

* **`>`** — перенаправить вывод в файл (перезаписать):
  ```bash
  echo "Привет" > hello.txt
  ```
* **`>>`** — дописать в конец файла (без перезаписи):
  ```bash
  echo "Мир" >> hello.txt
  ```
* **`<`** — подать содержимое файла на вход команде:
  ```bash
  wc -l < hello.txt
  # Аналог 'cat hello.txt | wc -l', но без лишнего процесса cat
  ```

## 3. Редактор потоков `sed`

`sed` (*stream editor*) применяется для трансформации и замены текста в потоке.

### Базовая замена: `s/что/на_что/флаги`

```bash
echo "hello world" | sed 's/hello/привет/'
# Вывод: привет world
```

* `s` — замена (substitution).
* `/hello/` — искомый шаблон.
* `/привет/` — текст для замены.
* `g` (global) — заменяет все вхождения в строке (по умолчанию меняется только первое):
  ```bash
  echo "кот, кот и еще кот" | sed 's/кот/пёс/g'
  # Вывод: пёс, пёс и еще пёс
  ```

### Регулярные выражения и группы захвата (Capture Groups)

Группы позволяют извлечь конкретную часть строки и вытащить только её.

1. Нужная часть оборачивается в скобки `\( ... \)` (в обычном режиме) или `( ... )` (с флагом `-E`).
2. В части замены мы ссылаемся на группу через `\1`, `\2` и т.д.

**Пример:** извлечь слово "Senior":
```bash
echo "Senior Data Scientist" | sed 's/\(Senior\).*/\1/'
# Вывод: Senior
```
* `\(Senior\)` — запоминаем слово как группу №1.
* `.*` — любые символы после слова.
* `/\1/` — заменяем всю строку на содержимое группы №1.

Если искомое слово находится в середине:
```bash
echo "Мой любимый цвет - красный, потому что..." | sed 's/.*\(красный\).*/\1/'
# Вывод: красный
```

### Сложные примеры фильтрации

Задача: оставить только квалификацию (`Junior`, `Middle` или `Senior`), а если её нет — заменить строку на `-`.

* **Вариант 1 (с флагом `-E` и пайплайном):**
  ```bash
  sed -E 's/.*((Junior|Middle|Senior)(\/(Junior|Middle|Senior))*).*/\1/' test.txt | \
  sed -E '/^(Junior|Middle|Senior|Junior\/Middle|Junior\/Senior|Middle\/Junior|Middle\/Senior|Senior\/Junior|Senior\/Middle)$/!s/.*/-/'
  ```

* **Вариант 2 (с условиями внутри одного блока `sed`):**
  ```bash
  sed -E '
    /(Junior|Middle|Senior)/ {
      s/.*((Junior|Middle|Senior)(\/(Junior|Middle|Senior))*).*/\1/
    }
    !(Junior|Middle|Senior) {
      s/.*/-/
    }
  ' test.txt
  ```

## 4. Сетевые запросы и API

### `curl` — передача данных по URL

`curl` (*Client URL*) — утилита для работы с сетевыми запросами (HTTP, HTTPS, FTP, SFTP и др.). Выполняет роль «браузера без графического интерфейса», возвращая сырой ответ сервера.

```bash
curl https://api.hh.ru/vacancies?text=data+scientist&per_page=1
```

#### Ключевые флаги `curl`:
* `-s` (*silent*) — отключить прогресс-бар (чтобы не загрязнять вывод/файл).
* `-o filename` — сохранить результат в файл.
* `-O` — сохранить в файл с оригинальным именем на сервере.
* `-L` (*location*) — автоматически следовать HTTP-редиректам (301/302).
* `-v` (*verbose*) — подробный лог запроса и ответа (заголовки, IP, статусы) для отладки.
* `-H "Header: Value"` — передача заголовков (например, авторизация или формат ответа).

#### Безопасная работа с токенами
Не хардкодьте секреты в скриптах! Используйте переменные окружения:

```bash
export HH_TOKEN="your_secret_token"

curl -s \
  -H "Authorization: Bearer $HH_TOKEN" \
  -H "Accept: application/json" \
  "https://api.hh.ru/vacancies"
```

### Основы HTTP API и REST

* **API (Application Programming Interface)** — контракт взаимодействия между системами.
* **REST (Representational State Transfer)** — архитектурный стиль построения API:
  * Клиент и сервер разделены.
  * Stateless (сервер не хранит сессию; каждый запрос содержит все данные для обработки).
  * Единообразие ресурсов и методов.

#### Структура HTTP-запроса
1. **Метод и путь:** `GET /api/v1/users`
2. **Заголовки (Headers):** `Host`, `Content-Type`, `Authorization`, `Accept`.
3. **Тело (Body):** Данные запроса (используются в `POST`, `PUT`, `PATCH`).

#### Основные методы HTTP:
* **`GET`** — запросить данные с сервера (метод по умолчанию в `curl`).
* **`POST`** — отправить данные на сервер (создание ресурса).
  ```bash
  curl -X POST https://httpbin.org/post -d "name=Alice&age=30"
  ```

## 5. Обработка structured data (JSON и CSV)

### Формат CSV (Comma-Separated Values)
Стандарт для текстового представления табличных данных:
1. Первая строка — имена колонок (header).
2. Разделитель — запятая `,` (или `;`).
3. Если значение содержит запятую, кавычку или перенос строки — оно оборачивается в двойные кавычки `"..."`.
4. Внутренние кавычки дублируются: `Он сказал "Привет"` $\rightarrow$ `"Он сказал ""Привет"""`.

### Утилита `jq` — обработка JSON

`jq` принимает JSON, применяет фильтр и возвращает преобразованный результат.

* `.` — вернуть исходный объект (Identity).
* `.key` — доступ к полю по ключу:
  ```bash
  echo '{"name": "Alice", "age": 30}' | jq '.name'
  # Вывод: "Alice"
  ```
* `.array[]` — «распаковать» массив на отдельные объекты.
* `[.id, .name]` — сформировать новый массив из выбранных полей.
* `@csv` — форматирование массива в валидную CSV-строку.
* `-r` (*raw output*) — вывод в виде чистой строки без JSON-кавычек и экранирования (обязателен при генерации CSV).

**Пример конвертации JSON в CSV:**
```bash
echo '[1, "Dev, Python", true]' | jq -r '@csv'
# Вывод: 1,"Dev, Python",true
```

## 6. Сортировка и анализ данных

### `sort` — сортировка строк
* `-r` — сортировка в обратном порядке (descending).
* `-n` — числовая сортировка (а не алфавитная).
* `-t 'разделитель'` — указать символ-разделитель колонок.
* `-k N` — сортировать по N-й колонке.
* `-u` — оставить только уникальные строки.

### `head` и `tail` — просмотр фрагментов
* `head -n 5 file.txt` — первые 5 строк.
* `tail -n 5 file.txt` — последние 5 строк.
* `tail -n +2 file.txt` — пропустить 1-ю строку и вывести всё, начиная со 2-й.

#### Обработка CSV с сохранением заголовка
Чтобы отсортировать CSV-файл, не смешивая строку-заголовок с данными:

```bash
# 1. Сохраняем заголовок
head -n 1 students.csv > header.txt

# 2. Сортируем только данные (со 2-й строки) по 3-й числовой колонке
tail -n +2 students.csv | sort -t ',' -k 3 -n > sorted_data.txt

# 3. Объединяем заголовок и отсортированные данные
cat header.txt sorted_data.txt > final_sorted.csv
```

### Подсчет уникальных значений (`cut`, `sort`, `uniq`)

Классический пайплайн аналитики в терминале:

1. **`cut`** — извлечение колонок:
   * `-d ','` — разделитель.
   * `-f 2` — номер колонки.
   ```bash
   echo "id,age,name" | cut -d',' -f2
   ```

2. **`uniq`** — схлопывание дубликатов:
   * **Важно:** `uniq` обрабатывает только *подряд идущие* дубликаты, поэтому перед ним всегда вызывают `sort`!
   * `-c` — посчитать количество повторений.

**Пайплайн подсчета частоты элементов:**
```bash
sort fruits.txt | uniq -c | sort -rn
```

## 7. Циклы и партиционирование данных

### Партиционирование
Разбиение крупных массивов данных (например, огромных логов) на мелкие файлы (партиции), чаще всего по датам или категориям.

### Циклы `while read` в Bash

Построчное чтение и обработка файлов:

```bash
cat names.txt | while read name; do
    echo "Привет, $name!"
done
```

#### Безопасный шаблон чтения файлов
Для корректного сохранения пробелов и спецсимволов используется сброс `IFS` и флаг `-r`:

```bash
while IFS= read -r line; do
    echo "Полученная строка: $line"
done < "input.txt"
```

* `IFS=` (*Internal Field Separator*) — отключение разделения по пробелам/табуляциям, сохраняет пробелы в начале и конце строк.
* `read -r` — отключает экранирование через обратный слэш `\`.
