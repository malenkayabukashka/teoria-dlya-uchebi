## Точка входа и типы данных

### Конструкция if __name__ == '__main__':
Это стандартный паттерн в Python. Когда ты запускаешь скрипт напрямую (например, `python3 data_types.py`), специальная переменная `__name__` автоматически получает значение `'__main__'`. Если же этот файл импортируют как модуль в другой скрипт, `__name__` будет равна имени файла. Эта конструкция гарантирует, что код внутри блока выполнится только при прямом запуске файла, что является строгим требованием твоего учебного плана.  

В языках программирования существует такое понятие, как точка входа. В некоторых языках программирования (C, C#, Go) конструкция `if __name__ == "__main__"` не требуется, потому что в самом начале разработки задается точка входа, без нее компилятор выдаст ошибку. Python же относится к этому лояльно и позволяет пользователю не указывать точку входу (Python в качестве точки входа считает первую строку), что может приводить к серьезным проблемам.  

### Операции
* **Арифметика:**

|Операция |	Символ | Пример| 	Результат
| :--- | :--- | :--- | :--- |
|Сложение|	+ |	2 + 3 |	5 |
|Вычитание|	- |	7 - 2 |	5 |

* **Условные операторы:**

```python
if condition:
    do_this()
```

Во всей конструкции ```if-elif-else` может быть выполнена только одна ветка: если расположенное выше условие истинно, то оставшиеся не проверяются. Для экономии времени выполнения кода условия, которые чаще оказываются истинными, стоит располагать выше. Если мы делаем проверку внутри функции, то полным аналогом кода выше будет такой код:

```python
def check_conditions():
    if condition:
        return start()
    if second_condition:
        return do_this()
    if other_condition:
        return do_that()
    
    return do_nothing()
```

```python
if condition:
    statement(s)
elif condition:
    statement(s)
else:
    statement(s)
```

Здесь, ```condition` является булевым выражением, которое принимает значение ```True` или ```False`. Если ```condition` имеет значение ```True`, тогда выполняются инструкции внутри блока ```if`. Если ```condition` имеет значение ```False`, тогда выполняются инструкции внутри блока ```elif`. Если ни одно из условий не является ```True`, тогда выполняются инструкции внутри блока else.

*Тернарный Оператор*  — предоставляют сжатый способ написания однострочного оператора if. Это встроенный оператор if, который состоит из трех операндов: условие, выражение для выполнения, если условие истинно, и выражение для выполнения, если условие ложно.

```python
<expression_if_true> if <condition> else <expression_if_false>
```

```python
# Проверка, Является ли Число Четным или Нечетным
num = 7
result = "Even" if num % 2 == 0 else "Odd"
print(result)  # Output: Odd
```

### Основные встроенные типы данных
1. `int` (integer) – целые числа (например, `42`, `-7`).  
2. `float` (floating point) – числа с плавающей точкой (например, `3.14`, `-0.01`).  
3. `str` (string) – строки, последовательность символов в кавычках (например, `"hello"`, `'data'`).  
4. `bool` (boolean) – логический тип, имеет только два значения: `True` или `False`.  
5. `list` – список, изменяемая упорядоченная коллекция элементов в квадратных скобках `[1, 2, 3]`.  
6. `dict` – словарь, изменяемая коллекция пар "ключ-значение" в фигурных скобках `{'a': 1, 'b': 2}`.  
7. `tuple` – кортеж, неизменяемая упорядоченная коллекция в круглых скобках `(1, 2, 3)`.  
8. `set` – множество, неупорядоченная коллекция уникальных элементов в фигурных скобках `{1, 2, 3}`.  

### Как узнать тип переменной?
```python
x = 10    
print(type(x)) # Выведет: <class 'int'>
```
💡 **Важный нюанс для задания:** Тебе нужно вывести имя типа как строку (например, `'int'`), а не весь объект `<class 'int'>`. У объекта, который возвращает `type()`, есть специальный атрибут `__name__`, который хранит именно строковое имя типа.  
```python
x = 10
print(type(x).__name__) # Выведет: int
```

```python
def data_types():
    my_int = 10
    my_str = 'hello'
    my_float = 3.4
    my_bool = True
    my_list = [1, 2, 3]
    my_dict = {"name": "Катя"}
    my_tuple = (1, 2, 3, "строка", True, [4, 5, 6])
    my_set = {"яблоко", "груша", "банан"}
    types_list = (
        type(my_int).__name__,
        type(my_str).__name__,
        type(my_float).__name__,
        type(my_bool).__name__,
        type(my_list).__name__,
        type(my_dict).__name__,
        type(my_tuple).__name__,
        type(my_set).__name__
    )
    print(f"[{', '.join(types_list)}]")

if __name__ == '__main__':
    data_types()
```

* `', '.join(types_list)` — метод строки `.join()` берет каждый элемент из нашего кортежа `types_list` и объединяет их в одну общую строку, разделяя запятой и пробелом `(", ")`.  
* `f"[{...}]"` — f-строка (форматированная строка) подставляет полученный результат внутрь квадратных скобок `[...]`.

## Строки (STRINGS)

Зафиксируем: обычная строка в Python — это объект типа `str`, предназначенный для хранения текстовых данных. Именно с такими строками разработчик работает чаще всего: получает текст от пользователя, обрабатывает данные, собирает сообщения, формирует URL, логи, SQL-запросы, HTML, JSON и многое другое.  

### Docstring
*Docstring* — это строка, которая размещается в начале модуля, функции, класса или метода и описывает, что именно делает этот объект. Обрамляется тройными ковычками:  
```python
def get_mock_info():
    """Возвращает информацию о теме мок-собеседования."""
    return "Сегодня разбираем ООП и классы"
```

### Raw-строки
Когда обратных косых черт много — например, в пути к файлу на Windows — экранировать каждую утомительно. Префикс `r` перед строкой отключает экранирование: все символы берутся буквально.  

*Обычную строку пришлось бы писать с двойными обратными слешами:*  
```python
raw_path = r"C:\Users\Documents\file.txt"
print(raw_path)
C:\Users\Documents\file.txt

s = r"Первая строка\nВторая строка"
print(s)
*Первая строка\nВторая строка*
```

### f-строки
f-строки позволяют встраивать выражения Python прямо внутрь строки, делая код более читаемым и лаконичным.  
```python
level = 50
s = f"Автора можно отблагодарить донатом {level} рублей или больше"
print(s)
```
До появления f-строк значения в строки обычно вставляли через конкатенацию, метод `.format()` или старый `%`-форматинг.  

В f-строку можно подставлять не только готовые значения из переменных, но и выражения.  
```python
junior_count = 12
middle_count = 8
s = f"На сайте boreesych.com доступно {junior_count + middle_count} записей для junior и middle"

level = "junior"
s = f"Уровень интервью: {level.upper()}"
print(s)
```

Кроме простой подстановки, f-строки умеют форматировать значения. Например, можно красиво выводить числа:  
```python
rating = 4.87654
s = f"Средняя оценка интервью: {rating:.2f}"
print(s)
Средняя оценка интервью: 4.88
```

Можно выравнивать текст:  
```python
level = "junior"
print(f"|{level:>10}|")
 |    junior|
```

Можно добавлять разделители разрядов:  
```python
views = 12500
print(f"Количество просмотров записей: {views:,}")
Количество просмотров записей: 12,500
```

У f-строк есть ещё одна удобная особенность, которая особенно нравится многим разработчикам при отладке:  
```python
level = "senior"
count = 3
print(f"{level=}, {count=}")
level='senior', count=3
```

Поскольку f-строки используют фигурные скобки для подстановки выражений, возникает вопрос: что делать, если в самой строке нужно вывести символы `{` и `}`?  
* Во-первых, f-строка вычисляется сразу в момент создания. Это не «ленивый шаблон», который потом можно отдельно применить к данным, а полностью готовая строка.  
* Во-вторых, чем сложнее выражения внутри фигурных скобок, тем хуже читаемость. Если внутри f-строки оказывается слишком много логики, это сигнал: часть вычислений лучше вынести в отдельные переменные.  

```python
user = {"level": "junior", "count": 7}
s = f"На сайте boreesych.com есть {user['count']} записей уровня {user['level'].upper()}"
print(s)
```
Код корректный, но иногда лучше сначала подготовить данные, а потом уже вставить их в строку.  

### t-строки
Template strings. На первый взгляд они очень похожи на f-строки: внутри тоже можно писать выражения в фигурных скобках. Но принцип работы у них другой. f-строка сразу вычисляется в готовый `str`, а t-строка возвращает не строку, а специальный объект `Template`, который хранит отдельно обычный текст шаблона и отдельно подставляемые значения.  
```python
level = "junior"
f_value = f"На сайте boreesych.com есть записи интервью уровня {level}"
template = t"На сайте boreesych.com есть записи интервью уровня {level}"

print(f_value)
print(template)
print(type(template))
```
```text
На сайте boreesych.com есть записи интервью уровня junior
Template(strings=('На сайте boreesych.com есть записи интервью уровня ', ''), interpolations=(Interpolation('junior', 'level', None, ''),))
<class 'string.templatelib.Template'>
```

Здесь видно, что типом t-строки будет уже не `str`, а объект шаблона `Template` из модуля `string.templatelib`. Именно так t-строки и задуманы: они дают доступ к структуре шаблона до того, как всё будет объединено в обычную строку. Это и есть главное отличие от f-строк.  

При этом t-строки не являются ленивыми шаблонами в духе `string.Template`: выражения внутри фигурных скобок вычисляются сразу, как и в f-строках.  

Особенность f-строк в том, что они слишком быстро превращаются в готовый текст. Это удобно, пока нам просто нужно красиво собрать сообщение. Но иногда разработчику важно не сразу получить финальную строку, а сначала посмотреть, что именно было подставлено, проверить значения, экранировать их, отфильтровать или обработать по специальным правилам. Именно для этого и появились t-строки.  

Важно понимать, что t-строка не предназначена для того, чтобы автоматически стать обычной строкой по встроенному правилу. Её идея в другом: сначала дать программе доступ к структуре шаблона и подставленным значениям, а уже потом позволить самой решить, как именно собрать итоговый результат.  

Здесь есть важный практический момент: t-строки появились только в Python 3.14. Это значит, что в большинстве существующих проектов, статей, курсов и продакшен-кодовых баз вы почти не встретите t-строк. В проектах, написанных на Python 3.12 или 3.13, такого синтаксиса ещё просто нет.  

### Комбинации префиксов
В Python 3.14 и новее `r` можно комбинировать с `f`, `t` и `b`: допустимы такие варианты, как `fr`, `rf`, `tr`, `rt`, `br` и `rb`. Порядок букв здесь роли не играет: такие варианты эквивалентны.

## Операции со строками

### Сложение
Строки можно складывать с помощью оператора `+`, чтобы создавать новые строки:  
```python
first_name = "Иван"
last_name = "Петров"
full_name = first_name + " " + last_name
print(full_name)
Иван Петров
greeting = "Привет, " + full_name + "!"
print(greeting)
Привет, Иван Петров!
```

### Повторение
С помощью оператора `*` можно повторить строку несколько раз:  
```python
border = "=" * 20
print(border)
====================
```

### Длина строки
Количество символов в строке узнаём через встроенную функцию `len()`:  
```python
word = "Python"
print(len(word))
6
empty = ""
print(len(empty))
0
```

### Доступ к отдельным символам
В строке к каждому символу можно обратиться по его позиции (индексу). Индексация начинается с 0, а отрицательные индексы отсчитываются с конца:  
```python
word = "Python"
first_letter = word[0]
second_letter = word[1]
last_letter = word[5]

print(f"Первая буква: {first_letter}")
print(f"Вторая буква: {second_letter}")
print(f"Последняя буква: {last_letter}")
Первая буква: P
Вторая буква: y
Последняя буква: n
# Можно также использовать отрицательные индексы для отсчета с конца
last_letter = word[-1]
second_last_letter = word[-2]
print(f"Последняя буква (с конца): {last_letter}")
print(f"Предпоследняя буква: {second_last_letter}")
Последняя буква (с конца): n
Предпоследняя буква: o
```

### Получение части строки (срезы)
```python
message = "Python Programming"
```
Синтаксис среза: `строка[начало:конец:шаг]`  
*начало включается, конец исключается*  

```python
first_word = message[0:6]     первые 6 символов   
print(f"Первое слово: {first_word}")
Первое слово: Python
second_word = message[7:]      от 7-го до конца  
print(f"Второе слово: {second_word}")
Второе слово: Programming
prefix = message[:6]           от начала до 6-го (не включая 6-й)  
print(f"Префикс: {prefix}")
Префикс: Python
every_second = message[::2]   каждый второй символ  
print(f"Каждая вторая буква: {every_second}")
Каждая вторая буква: Pto rgamn
reversed_string = message[::-1] строка задом наперед  
print(f"В обратном порядке: {reversed_string}")
В обратном порядке: gnimmargorP nohtyP
```

Срезы гибкие:  
* Если не указать начальный индекс, срез начнется с начала строки.  
* Если не указать конечный индекс, срез продолжится до конца строки.  
* Отрицательный шаг позволяет обходить строку в обратном порядке.

### Цепочки методов
Каждый строковый метод возвращает новую строку (помним про неизменяемость). А значит, их можно вызывать подряд через точку — результат одного сразу передаётся следующему. Это называется цепочкой методов.  

Например, нужно нормализовать пользовательский ввод: убрать лишние пробелы по краям и привести к нижнему регистру.  

В три шага через временные переменные:  
```python
raw_input = "  Hello  "
without_spaces = raw_input.strip()
normalized = without_spaces.lower()
```

Цепочкой в одну строку:  
```python
raw_input = "  Hello  "
normalized = raw_input.strip().lower()
print(f"'{normalized}'")
'hello'
```
Цепочки работают, потому что после `strip()` мы получаем новую строку, у которой тут же вызывается `lower()`. Это типичный паттерн Python-кода: вместо ведра промежуточных переменных — одна выразительная цепочка.

## Работа с файлами и табличными данными

### CSV и TSV
* **CSV (Comma-Separated Values)** — текстовый формат, где данные разделены запятыми:  
  *name,age,city*  
  *Alice,30,"New York"*  
  *Bob,25,"Los Angeles"*  
* **TSV (Tab-Separated Values)** — то же самое, но разделитель — табуляция (`\t`):  
  name	age	city  
  Alice	30	New York  
  Bob	25	Los Angeles  

### Работа с файлами
* **Открытие файла:**
  ```python
  file = open('имя_файла.txt', 'r')  # 'r' — режим чтения
  ```
  * **`'r'`** — чтение (файл должен существовать)  
  * **`'w'`** — запись (файл перезапишется, если существует)  
  * **`'a'`** — дозапись в конец файла  
  * **`'r+'`** — чтение и запись  

* **Чтение файла:**
  ```python
  content = file.read()        # Считать весь файл целиком
  lines = file.readlines()    # Считать все строки в список
  for line in file:            # Построчное чтение (экономит память)
      print(line)
  ```

* **Запись в файл:**
  ```python
  file.write('текст\n')        # Записать строку
  file.writelines(list_of_str) # Записать список строк
  ```

* **Закрытие файла:**
  ```python
  file.close()
  ```

### 🌟 Конструкция with (менеджер контекста)
Это лучший способ работы с файлами в Python. Она автоматически закроет файл, даже если произойдет ошибка:  
```python
with open('file.txt', 'r') as f:
    content = f.read()
# После выхода из блока with файл автоматически закрыт
```

### Парсер CSV
В CSV файле запятые могут встречаться внутри данных, если они заключены в кавычки:  
name,description,price  
"Apple","A sweet, juicy fruit",1.5  

Если ты просто сделаешь `line.replace(',', '\t')`, то запятая в слове `"A sweet, juicy fruit"` тоже заменится, и данные сломаются:  
`"Apple"	"A sweet	juicy fruit"	1.5`  ← НЕПРАВИЛЬНО!  

Правильный результат должен быть:  
`"Apple"	"A sweet, juicy fruit"	1.5`  ← ПРАВИЛЬНО!  

Нужно написать свой парсер CSV. Он должен:  
1. Идти по строке символ за символом.  
2. Отслеживать, находимся ли мы внутри кавычек (флаг `in_quotes`).  
3. Если встречаем запятую вне кавычек — заменяем на `\t`.  
4. Если встречаем запятую внутри кавычек — оставляем как есть.  
5. При встрече кавычки — переключаем флаг `in_quotes`.  

*Парсер* (от англ. parser; от *parse* — анализ, разбор) — это программа или часть программы, которая преобразует входные данные (обычно текст) в структурированный формат, удобный для дальнейшего анализа или использования.

## Списки 

### Списки (list)
это упорядоченная изменяемая коллекция элементов, которые могут быть разных типов: числа, строки, другие списки и так далее. Они позволяют хранить несколько значений в одной переменной и удобно работать с ними.

Есть несколько способов создать список в Python:

1. **Квадратные скобки.** Самый распространённый способ — перечислить элементы через запятую внутри квадратных скобок.
```python
numbers = [1, 2, 3, 4, 5]  # Список чисел
fruits = ['apple', 'banana', 'orange']  # Список строк
mixed = [1, 'hello', 3.14, True]  # Смешанный список
nested = [[1, 2], [3, 4], [5, 6]]  # Вложенный список
```
2. **Конструктор list().** Этот способ полезен, когда нужно преобразовать другой итерируемый объект (строку, кортеж, множество) в список.
```python
squares = [x ** 2 for x in range(1, 6)]  # [1, 4, 9, 16, 25]
```
3. **Генераторы списка.** Это компактный способ создать список на основе другого итерируемого объекта, часто с применением фильтрации или преобразования.
```python
chars = list('Python')  # ['P', 'y', 't', 'h', 'o', 'n']
tuple_to_list = list((1, 2, 3))  # [1, 2, 3]
```

**Основные свойства списков**
* **Упорядоченность.** Элементы следуют друг за другом в определённом порядке.
* **Изменяемость (мутабельность).** После создания списка его содержимое можно менять: добавлять, удалять или изменять элементы.
* **Гетерогенность.** В одном списке могут находиться объекты разных типов.
* **Динамичность.** Размер списка можно менять во время выполнения программы.

**Доступ к элементам**

Для обращения к элементам используется ```индекс` — порядковый номер, начиная с 0. Можно применять и отрицательные индексы, отсчитывая с конца списка.

```python
numbers = [1, 2, 3, 4, 5]
print(numbers)    # 1
print(numbers[-1])   # 5
print(numbers[1:4])  # [2, 3, 4]
``` 

Чтобы изменить элемент, достаточно присвоить новое значение по его индексу:
```python
numbers = 10  # Теперь numbers = [1, 10, 3, 4, 5]
``` 

**Основные методы списков**

| Метод | Что делает |
|---|---|
| `append(item)` | Добавляет элемент в конец списка |
| `insert(index, item)` | Вставляет элемент на заданную позицию |
| `extend(iterable)` | Расширяет список, добавляя элементы из итерируемого объекта |
| `remove(item)` | Удаляет первое вхождение указанного элемента |
| `pop(index=-1)` | Удаляет и возвращает элемент по индексу (или последний, если индекс не указан) |
| `clear()` | Удаляет все элементы из списка |
| `index(item)` | Возвращает индекс первого вхождения элемента |
| `count(item)` | Возвращает количество вхождений элемента |
| `sort(key=None, reverse=False)` | Сортирует список (по умолчанию по возрастанию) |
| `reverse()` | Переворачивает список |
| `copy()` | Создаёт копию списка |

**Встроенные функции**

Помимо методов, для работы со списками есть встроенные функции:
*   `len()` — возвращает количество элементов в списке.
*   `max()` и `min()` — возвращают наибольший и наименьший элемент.
*   `sorted()` — возвращает новый отсортированный список, не изменяя исходный.

## Словари 

### Словари (dict)
Словарь — это структура данных, хранящая пары "ключ: значение".  Они позволяют быстро получать значения по уникальному ключу, что делает их очень удобными для задач, где важен поиск по идентификатору, а не по индексу. 

Создание словарей с помощью:
1. **Фигурные скобки**
```python
capitals = {'Russia': 'Moscow', 'Ukraine': 'Kiev', 'USA': 'Washington'}
```
2. **С помощью функции dict()**
```python
capitals = dict(Russia='Moscow', Ukraine='Kiev')
capitals = dict([('Russia', 'Moscow'), ('Ukraine', 'Kiev')])
```
3. **С помощью метода dict.fromkeys()**
```python
days = ['Monday', 'Tuesday', 'Wednesday']
week_days = dict.fromkeys(days, 0)  # Все ключи получат значение 0
```
**Важно:** Нельзя создать словарь, указав только ключи без значений. Такой синтаксис интерпретируется как множество `(set)`.

**Основные операции и методы**
| Действие | Как сделать |
|---|---|
|Доступ к значению	| Используем ключ в квадратных скобках: dict['ключ']. Если ключа нет, возникает ошибка KeyError. Для безопасного доступа лучше метод get().|
|Добавление элемента |	Присваивание значения новому ключу: dict['новый_ключ'] = 'значение'. |
|Удаление элемента |	Оператор del: del dict['ключ']. Метод pop() удаляет элемент и возвращает его значение, что удобно, если нужно его использовать. |
|Перебор элементов |	Цикл for по умолчанию перебирает ключи. Для одновременного доступа к ключу и значению используйте метод items(). |
| Объединение словарей | Метод update() добавляет пары из другого словаря. При совпадении ключей значения из второго словаря перезаписывают предыдущие. |

```python
my_dict = {'Apple': 'AAPL', 'Tesla': 'TSLA'}
```
* **Доступ по ключу:** `my_dict['Apple']` вернет `'AAPL'`. Но если ключа нет, программа упадет с ошибкой `KeyError`.  
* **Безопасный доступ:** Метод `.get(ключ)` вернет значение, а если ключа нет — вернет `None` (или значение по умолчанию, если его указать: `.get('Facebook', 'Не найдено')`).  
* **Проверка наличия ключа:** Оператор `in`. Выражение `'Apple' in my_dict` вернет `True` или `False`.
