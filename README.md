# UNIX: инструменты командной строки
Командная оболочка (shell) — это программа, которая принимает команды, введенные с клавиатуры, и передает их операционной системе для выполнения.
Практически все дистрибутивы Linux поставляются с командной оболочкой изпроекта GNU, которая называется bash. Имя bash — это аббревиатура от названия
Bourne Again Shell, отражающего тот факт, что bash является улучшенной заменой sh, первоначальной командной оболочки для Unix, написанной Стивом Борном (Steve Bourne).  

**Создать переменную:**  
MY_NAME="Алиса"  
**Обратиться к переменной**  
echo $MY_NAME  
**Вставить переменную внутрь строки**  
echo "Привет, ${MY_NAME}!"  

**Подстановка команд**  
TODAY=$(date +%Y-%m-%d)  
echo "Сегодня $TODAY"  
*Сегодня 2026-10-16*  

**Конвейер (pipe) |** - это труба. Она берёт вывод одной команды и передаёт его как ввод следующей.
Читается слева направо: "сделай первое, потом результат отдай во второе, потом в третье..."  
*ls | grep ".json"*  
ls — выводит список всех файлов  
| — передаёт этот список дальше  
grep ".json" — из этого списка оставляет только строки, содержащие .json  

*echo "привет мир" | wc -w*  
echo — печатает строку  
| — передаёт строку дальше  
wc -w — считает количество слов (word count)  
*Выведет: 2*  

**Перенаправление вывода > и <**  
echo "Привет" > hello.txt  
*Теперь в файле hello.txt лежит текст Привет.*  
'>>' — дописать в конец файла (не перезаписывать):
echo "Мир" >> hello.txt  
Теперь в файле:  
*Привет*  
*Мир*  
< — подать файл как ввод команде:  
wc -l < hello.txt  
*Это то же самое, что cat hello.txt | wc -l, но короче.*  

**sed — замена текста** 
sed — это "stream editor", редактор потоков. Самая частая команда — замена: *s/что/на_что/g*.  
echo "hello world" | sed 's/hello/привет/'  
*Выведет: привет world*  
s — команда substitution (замена)  
/hello/ — что ищем  
/привет/ — на что заменяем  
g в конце (global) — заменить все вхождения в строке, а не только первое  

**curl — запрос к сайту**  
curl — утилита для HTTP-запросов. Специальная программа, которая позволяет делать сетевые запросы по различным протоколам данных (HTTP, FTP, SCP). Простейший вызов:  
*curl https://api.hh.ru/vacancies?text=data+scientist&per_page=1*  
Он сделает GET-запрос и выведет ответ (JSON) прямо в терминал.  

Важные флаги:  
**-s** (silent) — не показывать прогресс-бар (чтобы он не попал в файл).По умолчанию curl показывает прогресс-бар загрузки. Это полезно, когда ты смотришь в терминал. Но если ты сохраняешь результат в файл, прогресс-бар попадёт в файл и сломает JSON  
**-o filename** — сохранить в файл. Вместо вывода на экран  
**-O** — сохранить с оригинальным именем
**-L** (location) — следовать редиректам. Иногда сервер отвечает: "Иди на другой адрес" (HTTP 301/302). По умолчанию curl не идёт туда, он просто показывает тебе ответ "иди туда-то". Флаг -L говорит: "Иди, куда тебя посылают, и верни мне финальный ответ".  
**-v** (verbose) — подробный вывод. Показывает все детали запроса: заголовки, которые ты отправил, заголовки, которые пришлёт сервер, IP-адреса и т.д. Полезно для отладки.  
**-H** "Header: value" — добавить HTTP-заголовок (например, для авторизации). Сервер видит заголовок Authorization, проверяет токен и пускает тебя.  
*curl -H "Authorization: Bearer YOUR_TOKEN_HERE" https://api.hh.ru/vacancies*  
Никогда не пиши токен прямо в скрипте! Если ты закоммитишь такой скрипт в Git, токен уйдёт в публичный доступ, и злоумышленники смогут использовать твой аккаунт.  
Правильный способ — через переменную окружения:  
export HH_TOKEN="твой_секретный_токен"  
В скрипте:  
curl -s -H "Authorization: Bearer $HH_TOKEN" "https://api.hh.ru/vacancies"  
Указать формат данных  
*curl -H "Accept: application/json" https://api.example.com/data*  
Ты говоришь серверу: "Пожалуйста, пришли мне JSON".

curl (читается "сёрл", от "Client URL") — это утилита командной строки для передачи данных по URL. Она умеет работать с кучей протоколов: HTTP, HTTPS, FTP, SFTP и другими.  

Проще говоря: curl — это браузер без окошка. Когда ты открываешь сайт в Chrome, браузер делает HTTP-запрос, получает HTML и рисует красивую страничку. curl делает тот же запрос, но показывает тебе "сырой" ответ — текст, JSON, XML или что там пришлёт сервер.  

**API (Application Programming Interface)** — это контракт, определяющий, как одно приложение может взаимодействовать с другим. В контракте зафиксированы основные параметры: доступные методы, форматы запросов и ответов, аутентификация. HTTP API — это интерфейс, использующий протокол HTTP/HTTPS для передачи данных. Чаще всего HTTP API соответствует стилю REST, где ресурсы доступны по URL, а действия над ними выполняются через HTTP-методы.  
**REST (Representational State Transfer)** — это архитектурный стиль, описывающий набор принципов построения API. В большинстве случаев HTTP API создается как RESTful API, но эти понятия не синонимичны.  
- Клиент и сервер независимы, общаются через API  
- Отсутствие состояния: каждый запрос содержит всю необходимую информацию. Сервер не хранит состояние сессии.  
- Единообразие: API организован по ресурсам, с API работают с помощью стандартных HTTP-методов.

**Структура HTTP-запроса:**  
Ниже показана структура HTTP-запроса. Именно так он выглядит для самого протокола, но не все поля этого запроса нужны всегда, а в разных клиентах некоторые поля можно не заполнять. Например, в curl запрос без указанного метода будет считаться GET-запросом.  
1) Метод и путь. Пример: GET /api/v1/users
2) Заголовки (Headers)
- Host: адрес хоста и, опционально, номер порта;
- Content-Type: тип данных в теле запроса (application/json);
- Authorization: токен доступа;
- Accept: какие форматы ответа ожидает клиент;
3. Тело (Body) — только для методов, предполагающих отправку данных (POST, PUT, PATCH). Пример: { "name": "Иван", "email": "ivan@example.com" }

GET — "дай мне данные". Используется, когда ты хочешь получить что-то с сервера. Например, открыть страницу или скачать файл. Это метод по умолчанию в curl.  
curl https://api.github.com/users/torvalds  
POST — "возьми мои данные и сделай что-то". Используется, когда ты хочешь отправить данные на сервер. Например, создать нового пользователя, отправить форму, загрузить файл.
curl -X POST https://httpbin.org/post -d "name=Alice&age=30"

**CSV (Comma-Separated Values)** - это текстовый формат для хранения табличных данных. Его обожают в Data Science, потому что его понимают абсолютно все: Excel, Python (pandas), базы данных (PostgreSQL) и даже простые текстовые редакторы.  
1. Заголовки: Первая строка всегда содержит названия столбцов.  
2. Разделитель: По умолчанию это запятая , (иногда точка с запятой ; в русском Excel, но в UNIX-мире и Data Science стандартом является именно запятая).  
3. Главное правило кавычек: Если значение в ячейке содержит запятую, перенос строки или двойную кавычку, всё это значение обязательно должно быть обернуто в двойные кавычки " ".  
4. Экранирование кавычек: Если внутри значения есть двойная кавычка, она удваивается. Например, текст Он сказал "Привет" в CSV будет записан как "Он сказал ""Привет"""
"id","name","salary"
"123","Data Scientist, Python, ML","100000"

**jq** читает JSON, применяет к нему фильтр и выдает результат. Фильтр — это цепочка операций, разделенных вертикальной чертой | (как pipe в bash).
**Точка . (Identity)** - означает "взять текущие данные".
echo '{"name": "Alice"}' | jq '.'  
*Выведет весь JSON красиво*  
**Доступ к полю .key**  
echo '{"name": "Alice", "age": 30}' | jq '.name'
*Выведет: "Alice" (обрати внимание на кавычки, это всё ещё JSON-строка)*  
**Раскрытие массива .array[]**  
Это самый важный оператор для нашего задания. API HeadHunter возвращает объект, внутри которого есть массив items со списком вакансий.
Если мы напишем .items, мы получим один большой массив.
Если мы напишем .items[], jq "распакует" массив и выдаст каждый элемент по отдельности, как отдельный JSON-объект.  
**Создание нового массива [a, b, c]**
echo '{"id": 1, "name": "Dev", "city": "Moscow"}' | jq '[.id, .name]'  
*Выведет: [1, "Dev"]*  
**Магический форматтер @csv**  
Этот оператор берет массив и превращает его в строку формата CSV, автоматически расставляя кавычки и экранируя запятые по правилам, которые мы обсудили выше.  
Важно: @csv работает только с массивами! Если передать ему просто строку или объект, он выдаст ошибку.  
echo '[1, "Dev, Python", true]' | jq '@csv'
*"1,\"Dev, Python\",true"  (идеальный CSV!)*  

**-r** *по умолчанию jq всегда выводит валидный JSON. То есть строки будут обернуты в кавычки, а специальные символы экранированы.
Флаг -r говорит jq: "Выводи чистый текст, без JSON-оберток". Для создания CSV-файла этот флаг обязателен.*  

**Сортировка данных в UNIX**  
**sort** — это утилита командной строки, которая сортирует строки в файле или потоке данных. По умолчанию она сортирует строки в алфавитном порядке (лексикографически).  
sort [опции] [файл]  
**-r** Обратный порядок (Z-A)  
**-n** Числовая сортировка  
**-t символ** Указать разделитель полей *sort -t ',' file.csv*  
**-k номер** Сортировать по конкретному полю *sort -t ',' -k 2 file.csv*
**u** Убрать дубликаты sort -u file.txt  

**head** — показать первые строки  
head -n 5 file.txt    *Показать первые 5 строк*  
head file.txt         *По умолчанию показывает первые 10 строк*  

**tail** — показать последние строки  
tail -n 5 file.txt    *Показать последние 5 строк*  
tail file.txt         *По умолчанию показывает последние 10 строк*  

**Как использовать для сохранения заголовка**
*Чтобы отсортировать CSV без заголовка, нужно:*  
1. Выделить первую строку (заголовок) через head -n 1  
2. Выделить все остальные строки через tail -n +2 (начиная со 2-й строки)  
3. Отсортировать только данные  
4. Склеить заголовок и отсортированные данные  
# Сохранить заголовок  
head -n 1 students.csv > header.txt  

# Отсортировать всё кроме заголовка  
tail -n +2 students.csv | sort -t ',' -k 3 -n > sorted_data.txt  

# Склеить заголовок и данные  
cat header.txt sorted_data.txt > final_sorted.csv  

*tail -n +2 file.csv | sort -t ',' -k 2 | head -n 10*  
Читается: "Возьми все строки кроме первой, отсортируй по 2-му полю, покажи первые 10 результатов".  

sort -k 4 -r *Сортирует по 4-му полю, но -r применяется ко всей сортировке*  
sort -k 4,4r *Сортирует по 4-му полю, -r только для этого ключа*
